SHORT DESCRIPTION:
Relieve tinnitus with personalized sound therapy and calming noise tools.

FULL DESCRIPTION:
CalmTinnitus helps reduce tinnitus awareness using tone-matching, neuromodulation, and calming noise therapy.

Features:
• Tinnitus pitch matching
• White, pink, and brown noise
• Neuromodulation (alpha entrainment)
• Save your personal sound profile
• Simple, clean interface

No data collected. No tracking. No ads.

NOTES:
This app does not diagnose or cure tinnitus.
